## 0. 合规声明（先说清楚，这是这条路径成立的前提）

本简报**只使用了元数据**：歌名、歌手、榜单位次。

- ✅ **没有下载任何音频**，没有采样、没有扒旋律、没有抄歌词
- ✅ 借鉴的是**风格与手法**（曲风 / BPM 区间 / 段落结构 / 配器思路 / 情绪曲线 / 人声类型）
  —— 著作权保护「表达」，不保护「风格」
- ✅ 每张卡的 `remix.avoid` 固定写死四条：**原曲旋律走向 / 原歌词句式 / 标志性乐器动机 / 原唱音色模仿**
- ⚠️ **交付形态**：最终产出是**词曲全新的原创曲**，著作权可完整让渡给采购方 ——
  这正是不用「二创热歌」的原因（详见 `docs/hot-music-remix-compliance.md`）

### 1.5 情绪（仅统计已判定的 43 首）

## 2. 提取出的主导风格（一个）

# 「中慢板 · 华语情感抒情」＋ 千禧怀旧质感

**为什么是它**：它同时满足三个条件 ——
① 占比最高（抒情 / 都会流行 31%，单一体裁里第一）；
② **唯一横跨「千禧经典」与「近作」两轨**的共同项（说唱、国风、舞曲都只是单轨点缀）；
③ 与文旅的天然契合度最高（地标需要抒情与凝视，不需要 124 bpm 的舞曲）。

**它不是什么**：不是国风（仅 8%）、不是说唱（仅 5%）。
这两类是**调味料**，可以在段落里点缀，但做主轴会偏离榜单主旨。

## 3. 文旅创作简报（可直接执行）

### 3.1 风格配方

| 维度 | 取值 | 依据 |
|---|---|---|
| 曲风 | 华语情感抒情（Mandopop emotional ballad），带千禧怀旧质感 | §2 |
| BPM | **76–88**（中慢板） | 千禧抒情与近作网络抒情的高度重叠区 |
| 调式 | 大调为主，副歌转明亮；桥段可借关系小调 | 榜单中"副歌放开"的普遍写法 |
| 拍号 | 4/4，浅 half-time 律动 | 抒情慢歌通用 |
| 配器 | 钢琴 + 弦乐铺底 + 原声吉他 + 轻打击 | 千禧抒情标准编制；文旅可加笛 / 古筝点缀 |
| 人声 | 真声主唱，副歌叠和声；**不模仿任何特定歌手音色** | 合规红线 |
| 混音 | 宽混响、留白多、低频收敛（适配人声与字幕） | 与榜单质感一致 |

### 3.2 段落结构 —— 必须**短前奏**

对应 `prompts.song_structure()` 的 150 秒档（**17 行**）：
```
主歌1×4 → 预副歌×2 → 副歌×4 → 主歌2×4 → 尾副歌×3
```

⚠️ **前奏硬约束：≤ 8 秒必须起唱。** 两个理由：

1. **榜单层面**：这批歌绝大多数是被当**短视频 BGM** 使用的，长前奏会被直接划走；
2. **我们自己踩过的坑**：北京项目真实人声 20.2s 才进入，用户直接反馈
   「从 58 秒开始才同步，歌词出来太早」——长前奏在文旅 MV 里是**交付事故**，不是风格选择。

> 若走 120 秒档（14 行：主歌1×4 / 副歌×4 / 主歌2×4 / 尾副歌×2），
> 则把「预副歌」砍掉 —— 但这样会丢掉情绪推升的关键 2 行，**建议优先 150 秒**。

### 3.3 情绪曲线

```
主歌（克制、低语） → 预副歌（推升、密集合成器渐入）
  → 副歌（放开、弦乐全开） → 主歌2（回落但更暖）
  → 尾副歌（最强，可加童声/合唱垫底）
```

### 3.4 歌词主题角度（文旅化）

榜单主题是「错过 / 离别 / 思念 / 归途」—— 把**个人情感**锚到**具体目的地**即可完成转译：

| 榜单母题 | 文旅转译 |
|---|---|
| 思念 | 一座具体的地标作为思念的坐标（如"那年冬天的那片雪原"） |
| 归途 | 从远方回到一个可考的地名，副歌给出地名 |
| 错过 | 与一座城的擦肩，用当地真实景观承载遗憾 |
| 治愈 | 在当地真实场景中完成和解 |

**硬约束**：意象必须**可考**（真实存在的景观），不能写泛化的"远方""那片天"。
这与逐句配图的「真实景区 + 人工审核」闸门是同一套要求。

### 3.5 可直接下发的 style_prompt（给 Mureka）

```
mandopop emotional ballad, warm nostalgic 2000s tone, 82 bpm, 4/4 half-time feel,
piano and string pads with acoustic guitar, light percussion, sincere lead vocal
with harmony layers on chorus, wide reverb, restrained low end, spacious arrangement,
strong singable chorus, very short intro
```

> 注：项目 `mureka.py` 把 `brief.style_prompt` 原样作为 `prompt` 发给上游，
> 这段可直接填入项目简报。

### 3.6 避让清单（写死在卡片的 `remix.avoid`）

- 原曲旋律走向
- 原歌词句式
- 标志性乐器动机
- 原唱音色模仿

**判定线**：产出若能让普通听众「一听就想到榜单里某一首」，即越界，必须重做。
