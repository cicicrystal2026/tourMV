## 1. 本周最重要的一个发现：怀旧与上新，走的是两条通道

| 榜单性质 | 经典怀旧（≤2010）占比 |
|---|---|
| **存量热度**（抖音榜 / 热歌榜） | **60% / 40%** |
| **近期上行 + 新歌**（流行指数 / 新歌榜 / 飙升榜） | **5% / 0% / 0%** |

**读法**：老歌**占据了存量播放**，但**完全不参与"上行"**。
换句话说 —— 短视频里的「持久 BGM」是怀旧，新歌只能靠「短爆（飙升）」挤进来。
这两套机制并行，而文旅 MV 要的是**能长期留在场景里的那一类**，也就是左边这列。

**抖音榜 Top20 里 12 首是 ≤2010 的老歌**：晴天(2003)、雨爱(2008)、Always Online(2008)、
发如雪(2005)、情歌(2009)、夜曲(2005)、我怀念的(2007)、红色高跟鞋(2008)、红尘客栈(2012)、
演员(2015)、开始懂了(2000)、富士山下(2006)、偏爱(2009)……

> 与我此前基于你那份备忘录得出的结论**方向一致**，但这次的证据强得多 ——
> 那次是 24%，这次抖音榜是 **60%**，而且是从平台官方榜单直接取的当日数据。

## 2. 第二发现：本周真正「新」的爆款，来自影视剧原声

**QQ音乐新歌榜 20 首里，有 6 首出自同一部剧《兰香如故》**（占 30%）：
大梦归 · 静待清光 · 一曲微茫 · 深深的我们 · 花开满篱院 · 同道。

而**跨榜第一名**（同时登上 **4 个榜**）正是这部剧的主题曲 **《大梦归》（周深）**。

**含义**：当下「最新的爆款」并不是独立单曲，而是**影视剧 OST**，且是**古装剧的国风抒情**。
这与文旅 MV 的基因（叙事 + 文化意象 + 地标）几乎同构 —— 比模仿独立音乐人的作品更可借鉴。

| 上榜数 | 歌曲 | 歌手 | 风格 |

## 5. 提取出的主导风格（2026-W41 版）

# 「中慢板 · 华语情感抒情」＋ 国风影视质感

与上一版（备忘录基线）相比，**主轴不变，但配器与题材来源更明确了**：

1. 抒情·都会流行仍是第一体裁（24%）—— **主结构不变**；
2. **国风（11%）+ 影视 OST（8%）合起来近两成**，且新歌榜的"最新爆款"几乎全在这里；
3. 情绪关键词是 **宿命 / 辽阔 / 怅然 / 等待** —— 这正是国风叙事的语汇，也**天然适配文旅的在地叙事**。

**所以本周的最优借鉴对象不是某首独立单曲，而是「古装剧主题曲」这一形态。**

## 6. 文旅创作简报（可直接执行）

| 维度 | 取值 |
|---|---|
| 曲风 | 华语情感抒情 ＋ **国风影视质感**（cinematic mandopop / guofeng OST） |
| BPM | **76–88**（中慢板，与上周一致） |
| 调式 | 大调为主，副歌转明亮；桥段借关系小调制造"宿命感" |
| 拍号 | 4/4，浅 half-time |
| 配器 | 弦乐铺底为骨架 + **古筝 / 竹笛点缀** + 钢琴 + 轻打击 |
| 人声 | 真声主唱；副歌叠和声，可加一段吟唱。**不模仿任何特定歌手音色** |
| 混音 | 宽混响、留白多、低频收敛（适配人声与字幕） |

**段落结构**（对齐 `prompts.song_structure()` 的 150 秒档 → 17 行）：
```
主歌1×4 → 预副歌×2 → 副歌×4 → 主歌2×4 → 尾副歌×3
```

⚠️ **前奏 ≤ 8 秒必须起唱**。本周榜单再次印证：这批歌绝大多数是被当**短视频 BGM** 用的，
长前奏会被直接划走；且我们自己在长前奏上出过交付事故（北京项目真实人声 20.2s 才进）。

**情绪曲线**：
```
主歌（克制低语）→ 预副歌（弦乐渐入、推升）→ 副歌（弦乐全开、开阔）
→ 主歌2（回落但更暖）→ 尾副歌（最强，可加吟唱垫底）
```

**歌词主题角度**（本周情绪词 → 文旅转译）：

| 本周情绪 | 文旅转译 |
|---|---|
| 宿命 | 山河与人的相遇，用一座真实地标承载"命中注定要来一次" |
| 辽阔 | 大景别空镜对应的词——戈壁、雪原、海、高原 |
| 怅然 / 怀念 | 旧地重游，副歌给出具体地名 |
| 等待 / 归来 | 归途叙事，落到一个可考的村镇或站台 |

**硬约束**：意象必须**真实可考**，不写泛化的"远方""那片天"。

### 可直接下发的 style_prompt

```
chinese guofeng cinematic ballad, mandopop OST style, warm nostalgic tone, 82 bpm,
4/4 half-time feel, string section as backbone with guzheng and dizi accents,
piano and light percussion, sincere lead vocal with harmony layers on chorus,
wide reverb, restrained low end, spacious arrangement, strong singable chorus,
very short intro under 8 seconds
```

### 避让清单（已写死进 101 张卡片的 `remix.avoid`）

原曲旋律走向 · 原歌词句式 · 标志性乐器动机 · 原唱音色模仿
> **判定线**：产出若能让普通听众「一听就想到榜单里某一首」，即越界。
