# V1.1 W3 变更说明（真实能力：对齐 / 节拍 / 向量检索 / 出片自检）

依据：《文旅MV生产管线_V1.1_PRD》W3 里程碑与 F3-1、F3-2、F3-7、F3-10、F4-3、F4-4、F6-2、F1-2。
版本：V1.0.1 之后的 main。

---

## 一、部署前必须做的事

1. 安装可选依赖（`backend/requirements-optional.txt`，均已在 Python 3.14 上验证）：

   ```
   pip install librosa soundfile rapidocr transformers pillow
   pip install torch --index-url https://download.pytorch.org/whl/cpu   # 有 CUDA 的机器装对应版本
   ```

2. 首次启动会从 `HF_ENDPOINT`（默认 hf-mirror.com）下载 Chinese-CLIP 权重约 750MB，
   随后后台自动排一个「重建素材向量」任务，把库里旧的哈希占位向量全部重算（106 条约 2 分钟）。
3. 新增可选变量：`MATCH_THRESHOLD`（实拍「合格」匹配分阈值，默认 0.6）。
4. 数据库自动迁移：`asset.embedding_model`（只加列）。

## 二、改了什么

| PRD | 改动 | 以前的问题 |
|---|---|---|
| F3-1 | 歌词与歌声对齐失败时**任务失败并停在「音频分析」**，剪辑页给出原因和两个出口：「重试对齐」/「按字数估算继续（字幕可能不同步）」。失败不自动重试（重试必然同样失败，白跑几分钟 CPU） | 对齐失败静默回退成按字数估算，长白山样片字幕整体早了 25 秒 |
| F3-1 | 装上 librosa，节拍来自真实检测；用简报速度区间作先验，避免半速/倍速歧义 | 节拍是按 BPM 猜的网格 |
| F3-2 | 镜头切点吸附节拍：±0.5 秒内有强拍落强拍，否则落最近普通拍；AI 静态画面单段超过 8 秒时在强拍处拆段，各段取同一推镜素材的不同时间窗（远景→近景） | 不做吸附；前奏 + 第一句一张图撑十几秒 |
| F4-3 | 真 Chinese-CLIP：素材按关键帧（缩略图 + 1/2、3/4 处抽帧）编码；向量记录编码器版本，换编码器后自动重建；不同编码器的向量不相互比较 | 哈希占位编码，语义检索无效；且图像编码直接把 mp4 路径当图片 |
| F4-4 / F6-2 | 匹配分按实测区间标定为 0–1（画面相符 ≈0.8–1.0，不对题 ≈0.2–0.5）；逐句配图在素材库找实拍时，匹配分 ≥ 0.6 才算合格，否则走 AI 补位 | 按关键词命中数挑，常拿「同目的地但不相干」的镜头凑数 |
| F3-10 | 出片自检新增：在 5 句歌词的中点抽帧，OCR 画面下方，须 ≥80% 与此刻歌词一致；无字幕版确认没有字幕；音视频流起点/时长同步检查 | 只看「字幕文件里有没有歌词」，不看画面 |
| F3-7 | 剪辑页「导出 720p 预览」：720p、中间片段 ultrafast（2:43 的片 36 秒、14MB），不改项目状态、不进成片列表、不参与交付 | 只有一个返回命令字符串的空函数 |
| F1-2 | 看板 SSE 推送：后端每秒比对项目/任务变更，变了就推，看板 1 秒内刷新；推送不可用时退回 4 秒轮询 | 6 秒轮询，达不到「5 秒内」 |
| — | 修订版沿用原项目「保留原文」的决定（按类型 + 原句匹配，理由标明「沿用原项目的决定」）；原项目没处理过的疑点仍需人工 | 修订 2 要把 27 条疑点重新点一遍 |

## 三、验证

- 自动化：`backend/tests/test_p0.py` 32 个用例全部通过（新增：对齐不静默降级、强拍吸附与静态镜头拆分、匹配分标定与跨编码器隔离、修订版沿用决定、看板推送指纹）。
- 向量检索实测（106 条素材，真 Chinese-CLIP）：「天池 火山口湖」→ 天池分镜 1.0；「溪流 苔藓」→ 松花江源头 0.86；「海边 沙滩」库里没有，最高 0.49，低于合格线，正确地不匹配。
- OCR 自检实测：修订 2 的 4 个成片版本均 5/5 帧字幕一致；把时间轴人为平移 20 秒后自检正确失败，并指出「25s 应为『雪线之上…』识别为『图们鸭绿…』」。
- 端到端实测（长白山修订 3 / 修订 4，测试环境，0 元）：

  | 环节 | 结果 |
  |---|---|
  | 修订版疑点 | 修订 3：16 条中 14 条沿用原项目决定；修订 4：15 条全部沿用，0 条待处理 |
  | 生曲 | 沿用原曲，跳过生曲与选曲 |
  | 对齐 / 节拍 | whisper 对齐 19/19 句；librosa 69.8 BPM；前奏裁到人声 1.5 秒处 |
  | 粗剪 | 27 个片段，最长 7.73 秒（≤8 秒）；26/26 个切点落在节拍上 |
  | 720p 预览 | 2:43 的片 36 秒导出，14 MB |
  | 出片自检 | 5 个版本全部通过：字幕抽帧 OCR 5/5、无字幕版无字幕、音视频起点差 0.00 秒 |
  | 看板推送 | 新建项目后约 2 秒内收到 change 事件 |
