# 热歌参考与「二创」：合规判断与落地路径

> 场景：抓取抖音 / 视频号 / 小红书上近一个月的爆款音乐 → 下载 → 解构 → 作为创作简报参考 → 生成文旅 MV
>
> 结论：**「下载热歌当素材去二创」不可行；「把热歌当风格参数源」可行，且项目已有 80% 基建。**

---

## 一、结论先行

| 做法 | 法律 | 能否过文旅验收 | 建议 |
|---|---|---|---|
| 直接改编热歌旋律 / 重填词使用 | 需逐首取得改编权，权利人可拒绝 | ✗ 著作权给不了甲方 | ❌ 禁止 |
| 采样、拼接、变速截取热歌 | 侵权（复制权/改编权） | ✗ | ❌ 禁止 |
| 用剪映「商用音乐」当 BGM | 授权**仅限剪映/抖音平台内** | ✗ 多平台投放超范围 | ❌ 不可用 |
| 买正版曲库商用授权做 BGM | 合法 | ✓ 但曲目雷同、无独特性 | ⚠️ 可作备选 |
| **扒热歌的结构 / 节奏 / 调性 / 情绪，出原创曲** | **合法（风格不受保护）** | **✓ 词曲原创，著作权可归甲方** | ✅ **推荐** |
| AI 模仿特定歌手音色演唱 | 侵犯声音权益 + 改编权 | ✗ | ❌ 禁止（与既有红线一致） |

---

## 二、为什么「下载热歌 + 二创」走不通（四条硬伤）

### 硬伤 1：改编权拿不到，且不在「一揽子授权」范围内

很多人以为找音著协就能拿到改编许可 —— **这是错的**。

- 音著协官网明确：**音乐作品的改编等权利由权利人自己直接行使**；
- 上海市知识产权局公开表述：改编权仅属于著作权人，**不属于音著协集体管理的范畴，也就不属于「一揽子协议」的范畴**。

也就是说：**没有任何批量通道可以合法改编别人的歌**，必须逐首找到词曲著作权人本人（或其版权公司）谈。流程是：

> 提交改编后的歌词 + 音频 Demo + 使用场景 / 渠道 / 地域 / 期限 → 权利人审核 → 报价 → 谈判签约付款

**权利人有权直接拒绝。** 而短视频平台上的爆款热歌，恰恰是版权方最敏感、最可能拒绝的一类。

### 硬伤 2：没有「小节数」宽限，「不盈利 / 只改一小段 / 只用一次」都不是理由

音著协官方科普澄清过三个常见误解：

- 业界**不存在**「6 小节 / 8 小节以内不算改编」的宽限标准 —— 只要**实质性改变**了原作品内容，就涉及改编权；
- 改编的目的（做慈善 / 上节目 / 办活动）**不影响**侵权认定；
- 改动后**只用一次**也不是抗辩理由。

### 硬伤 3（最致命）：交付反噬 —— 著作权给不了甲方

文旅项目（尤其是政府采购）普遍要求**著作权永久归采购方**。参考真实采购文件：

| 项目 | 预算 | 关键要求 |
|---|---|---|
| 澄迈县旅文局《澄迈：新世界》音乐纪实片 | ≤18 万 | 4K 成片、5 分钟短片 ×2、标准字幕文件、**著作权永久归采购方** |
| 五指山市旅游宣传片 | ≤19 万 | 5min + 1min + 15~30s **三版本**、**中英文** |
| 合阳县文旅宣传片 | 120 万 | 全流程含推广 |

**二创热歌的原始权利人是别人。** 你哪怕花钱拿到了授权，也**不可能**把著作权转让给甲方 —— 等于花了钱还是交付不了。这一条决定了：二创热歌在文旅主交付场景里是**结构性不可行**，而不只是「有风险」。

### 硬伤 4：平台授权的隐性范围陷阱

剪映「商用音乐」条款原文（要点）：

> 您同意包含上述来源音乐或声音的任何视频**只能分发、共享和发布到剪映、抖音上（「许可平台」）**；如果您选择在许可平台以外的平台（包括但不限于电视、广播或戏剧媒体）上分发任何视频，**您应自行获得**音乐著作权所有者在平台上分发该视频的所有必要权利和许可。

文旅 MV 要投 **视频号 / 小红书 / 海外平台** —— 恰好全在「许可平台」之外。这条授权**直接废掉**。

### 叠加风险：AI 参与会再加一重

| 判例 / 事件 | 认定 |
|---|---|
| 杭州滨江法院（2026-07） | AI 处理后的声音，只要普通听众能识别出**特定自然人**，即落入声音权益保护范围 |
| AI 模仿碧昂丝声音改编《泡沫》 | 侵犯**改编权 + 声音权益**，作品下架 |
| 杭州互联网法院（2024）浙 0192 民初 1587 号「奥特曼案」 | 用户用 AI 生成**实质性相似**内容 → 侵改编权、复制权、信息网络传播权；平台未尽注意义务构成**帮助侵权** |
| 慕尼黑地院 2026-07-31 Suno / GEMA 一审 | **训练阶段复制版权作品本身即构成侵权**（不是输出成品才算） |

> 与本项目既有约定一致：**不做 AI 仿唱他人声线**（全国首例 AI 声音侵权案判赔 25 万，司法标准是「一听就能认出是谁」）。

## 三、可行的那条路：把热歌从「素材源」改成「参数源」

### 原理：著作权保护「表达」，不保护「风格」

受保护的是**具体表达**（旋律走向、歌词文本、录音制品）。
不受保护的是**风格与手法**：BPM、拍号、调式、和声进行类型、段落结构比例、配器思路、情绪曲线、人声类型、混音取向。

**只借鉴后者，是完全合法的。** 这也正是项目现有的 `TrendCard` 设计：

```
TrendCard
├── elements  genre / bpm / key_mode / time_feel / structure /
│             instrumentation / vocal_style / mood / energy / lyric_theme
└── remix     borrowable      → 可借鉴之处（手法层）
              style_prompt    → 直接下发给音乐模型的风格提示
              avoid           → 【原曲旋律走向 / 原歌词句式 / 标志性乐器动机】
```

`avoid` 这一项是**教科书式的正确设计** —— 它把「风格借鉴」与「表达复制」的边界写进了数据模型。**要做的不是重建，而是换数据源。**

### 已有基建盘点（不需要从零做）

| 组件 | 位置 | 现状 |
|---|---|---|
| 热歌采集 + 要素拆解 | `monitor.py`（外部脚本，`MONITOR_SCRIPT` 可配） | ✅ 已有，腾讯—— 数据源是 **YouTube**（Data API v3，`videoCategoryId=10`，按 region chart） |
| 素材卡同步服务 | `backend/app/services/trends.py` | ✅ 已有，复用 `monitor.py` 的 `rank()` / `analyze_one()` |
| 卡片表 | `trend_card` / `trend_snapshot` | ✅ 已有 |
| 简报挂卡 | `brief.trend_card_ids` | ✅ 已有字段，**但未接生产流程** |
| 接口 | `/api/trends/cards` `/status` `/sync` `/seed` | ✅ 已有 |
| 音乐生成用风格提示 | `adapters/music/mureka.py` → `body["prompt"] = req.style_prompt` | ✅ 已有 |
| 结构按目标时长分档 | `prompts.song_structure()` | ✅ 已有 |

**缺口只有一个：数据源是欧美日韩榜单，且没有把卡片真正喂进创作流程。**

## 四、三平台数据合规获取现状

**核心事实：抖音 / 小红书 / 视频号都没有开放的「全平台热榜」API。**
（地址已于 2026-10-10 逐个探测可用性）

| 平台 | 开放热榜 API | 合规获取路径与地址 |
|---|---|---|
| 抖音（官方） | ❌ | **抖音热点宝** `https://douhot.douyin.com`（官方热点分析，含音乐热点）<br>**抖音指数**（原巨量算数）`https://trendinsight.oceanengine.com`<br>**抖音 APP 内**：搜索「热歌榜」／音乐 → 排行榜（热歌榜、飙升榜） |
| 抖音（第三方） | ❌ | **飞瓜数据（抖音版）** `https://dy.feigua.cn` → 热门素材 → **热门音乐**；付费可导出<br>**蝉妈妈** `https://www.chanmama.com`（专业版可导出）<br>**新榜** `https://www.newrank.cn`（综合搜索可匹配近 30 天音乐，有企业版 API）<br>**抖查查** `https://www.douchacha.com`（主打热门 BGM / 话题结构 / 脚本拆解） |
| 小红书 | ❌ | **千瓜数据** `https://www.qian-gua.com`（付费）；**蒲公英** `https://pgy.xiaohongshu.com`（商单平台，非榜单）<br>官方**没有**音乐榜 |
| 视频号 | ❌ | **微信指数**（微信内「搜一搜」→ 微信指数，看关键词热度）；新榜有视频号板块<br>官方**没有**热歌榜 |
| YouTube | ✅ | 官方 Data API v3 —— **当前 `monitor.py` 用的就是这条** |

> ⚠️ **一处需要现场确认的变动**：巨量算数已于 **2026-01-01 正式升级为「抖音指数」**，
> 切换为抖音登录体系；有资料称升级后**不再提供「算数榜单 / 行业指南 / 区域指南」**，
> 但站点首页导航目前仍显示「算数榜单」（品牌榜 / 电商榜 / 热搜榜）。
> **以你登录后实际看到的为准** —— 热门音乐榜是否还在，需登录确认。
>
> ⚠️ **`music.douyin.com` 不是热歌榜**：它是「汽水音乐合作平台」（音乐人 / 厂牌入驻），
> 抖音**没有公开的网页版热歌榜**。

### 明确不要做的事：爬虫

- **刑法第 285 条**：突破反爬获取非公开数据，违法所得 5000 元以上即可追刑责；
- **不正当竞争**：「抖音诉某葫芦案」认定平台对数据享有竞争法上的合法权益；**小红书诉某数据公司案判赔 490 万**；
- 且爬虫拿到的音频仍然过不了上面四条硬伤 —— **风险极高、收益为零**。

## 五、一条要写进规范的红线

项目已定「**禁止从网上直接找图片 / 视频当素材**」（商用投放 + 版权）。**音频适用同一条，且更严。**

- 人工试听、听感参考 —— 可以做；
- **不要做批量下载脚本**（违反平台条款）；
- **不要把热歌音频放进 `data/`** —— `asset` 表有 `license_status / licensor / license_no`，
  入库等于自证侵权；
- `monitor.py` 的 `--audio-dir` 注释写的是「**本地合法音频目录**」—— 这个设计是对的，**保持**。

## 六、落地三步

### 阶段 1 · 零成本，可立即开始
人工从巨量算数 / 飞瓜导出榜单（截图或 CSV）→ 写一个导入脚本，
**只录元数据 + 风格标签，不碰音频** → 直接产出 `TrendCard`（复用现成结构）。

### 阶段 2 · 半自动
给 `monitor.py` 增加 `source=douyin / xhs` 采集器，**只采公开榜单元数据**，
复用它的 `rank()` 与 LLM 要素拆解 → 产出卡片。

### 阶段 3 · 全自动闭环
风格配方注入 `brief`（`genre` / `mood` / `bpm_min` / `bpm_max`）→
`song_structure()` 按目标时长定段落结构 → Mureka 出**原创曲** →
逐句配图 → 卡点 → 合成。

**最终产物：词是我们原创的文旅词，曲是 AI 原创，画面是真实景区 —— 版权链干净，著作权可以完整给甲方。**

## 七、风格配方模板（对齐现有 `TrendCard` 结构，可直接用）

```jsonc
// elements —— 客观特征（用于简报参考）
{
  "genre": "city pop revival",       // 曲风
  "bpm": "96-102",                   // 速度
  "key_mode": "A minor",             // 调性 / 调式
  "time_feel": "four-on-the-floor",  // 律动型
  "structure": "intro-verse-chorus-verse-chorus-outro",
  "length": "3:05",
  "instrumentation": ["电钢琴", "slap bass", "合成弦乐", "电子鼓"],
  "vocal_style": "中性中音",
  "mood": ["热闹", "怀旧"],
  "energy": "mid",
  "lyric_theme": "夜晚街市与旧友",
  "production_traits": ["80s 复古混音", "宽立体声"],
  "mv_visual_style": "夜景霓虹 + 手持跟拍",
  "confidence": { "bpm": "inferred", "genre": "inferred" }   // 标注推断项，人工复核
}

// remix —— 可借鉴层（真正下发给模型的部分）
{
  "borrowable": ["four-on-the-floor 底鼓", "电钢琴切分和弦", "预副歌的半音上行"],
  "style_prompt": "retro city pop revival, four-on-the-floor kick, electric piano stabs, slap bass, warm analog synth strings, 99 bpm, A minor",
  "lyric_angles_for_wenlv": ["把夜市写成可以走进去的场景", "用灯牌与摊位做副歌记忆点"],
  "visual_ideas": ["夜市灯牌延时", "手持跟拍走过小吃街", "雨后地面反光特写"],
  "avoid": ["原曲 bass line", "原曲和弦进行", "原歌词"]      // ← 边界，必须显式写出
}
```

> **判定标准一句话**：如果 `style_prompt` 交给模型后，产出的是**听不出原作的可识别片段**的新曲 —— 合规；
> 如果产出能让普通听众「一听就想到那首歌」—— 越界了。

## 八、单曲可行性核查清单（以《一路生花》为例）

遇到「能不能拿某首歌做二创」这类问题，按这五步核查，不要凭感觉。

### 以《一路生花》为例的核查结果

| 核查项 | 结果 |
|---|---|
| **权利归属** | 作词 宋普照 / 作曲 张博文 / 编曲 李师珏 / 原唱 温奕心，2021-01-19 发行；**OP = 广州繁星互娱信息科技有限公司**（酷狗·腾讯音乐系） |
| **有无授权渠道** | ✅ **有**。腾讯音乐旗下商用音乐授权平台「曲易买」（`quyimai.qq.com`）收录该曲，授权场景明确列有**商业广告/宣传片**与**改编/翻唱** |
| **地区 / 期限** | ⚠️ **授权地区：中国大陆；授权期：一年** —— 海外投放超范围，长期复播需续费 |
| **能否满足「著作权归甲方」** | ❌ **不能**。改编授权 ≠ 著作权转让，改编成果的权利链上仍有原始权利人 |
| **权利人是否主动维权** | ⚠️ **是，而且很积极**。2026-07 广州繁星互娱批量投诉，致 B 站 / 抖音系 / 快手**二创稿件成批下架**；番禺区法院审理的「某直播平台侵权案」（索赔 **近 7000 万元**、涉 7 家著作权公司 243 首歌）**核心标的即含此曲**，最终以「和解 + 授权」三年全曲库协议结案 |

### 由此提炼的判别规则

> **「找得到授权渠道」≠「能用于交付」。**
> 拿到商用/改编授权只解决「能不能用」，不解决「能不能交付」——
> 后者的门槛是**地区覆盖、授权期限、著作权能否让渡**。

**决策口径**：

| 你要的是什么 | 该走哪条路 |
|---|---|
| 甲方说「要一首像《一路生花》那样感觉的歌」 | ✅ **做原创曲**（借用风格配方），成本 ¥0.3–1/首，著作权完整可让渡 |
| 甲方明确说「就用《一路生花》这首歌」 | ⚠️ 走曲易买正规授权，但**签约前必须书面确认三件事**：<br>① 投放地区是否含海外 ② 授权期限是否覆盖项目生命周期 ③ **著作权归属**——若要求「永久归甲方」，这条路**直接不成立**，需回头改为原创 |

### 这首歌的创作侧评价（即便不走授权）

- **适配度高**：平台给它打的场景标签里**就有「旅行」**；主题（愿望 / 奔赴 / 绽放）与文旅的「向往」叙事天然契合；副歌第一句即达高潮，强记忆点。
- **但同质化严重**：央视新闻、人民日报、新华社、中国青年报均用作 BGM；短视频话题播放量 **37.4 亿**；印尼改编版海外观看 **13 亿次**；2024 年入选「五个一工程」。**直接二创出来的辨识度会很低**，而文旅项目恰恰需要辨识度。
- **时长注意**：原曲 **4:16**，文旅 MV 常见的 2–3 分钟交付需重编（截副歌）。若只借风格则无此问题。
